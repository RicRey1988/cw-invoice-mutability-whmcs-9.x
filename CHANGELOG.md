# Changelog

## 1.1.0

- Added advanced audited mode to convert eligible `Unpaid` invoices to `Draft`.
- Added snapshot logging for invoice data, invoice items, and transactions.
- Added restore-status workflow for invoices converted by the module.
- Added fiscal/external-document guard keywords.
- Added invoice-view helper button when Draft tools are enabled.
- Preserved official WHMCS compatibility flag workflow.

## 1.0.0

- Initial community release.
- Added admin interface to enable/disable invoice mutability.
- Added automatic `configuration.php` sync with backup.
- Added option to hide WHMCS immutability warning banner.
- Added Codigoweb.dev branding and PayPal donation link.
